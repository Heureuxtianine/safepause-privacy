设备连接

这里填写你部署的 SafePause 后端 HTTPS 地址和访问密钥。它只负责国产 AI、语音转写和 Skill；本机短信、电话、提醒仍走手机已授权接口。

普通用户不需要配置这里。网关由管理员绑定目标设备后使用；公开网页不能内置某一台手机的私有访问密钥。

如何连接不同品牌的设备？
  1. 在目标设备上安装或启用有系统操作能力的服务，按系统要求授权。
  2. 通过适配器将该服务接入 SafePause 网关；每个目标设备使用独立受控连接。
  3. 填写该设备的 HTTPS 网关地址与访问密钥，再回到“设备调用”探测工具。

网页运行在哪台手机上，不代表工具就会操作这台手机；调用的是网关实际连接的目标设备，发送或拨号前必须核对。

导入 Skill 只提供操作规则；实际运行还需要模型、智能体运行环境和设备工具。

如果只是老人日常使用，不需要修改这里的地址、密钥或模型。
