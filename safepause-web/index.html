设备调用

待探测

真实调用取决于本机或手机上的 MCP 服务、系统权限和本次授权。每项能力以当前探测结果为准。

此处填写 SafePause 网关地址，不是静态网页网址，也不是手机号码。网关须连接目标设备上已授权的服务；可更换网关连接其他设备，不限定手机品牌。请勿填写陌生人提供的网址或密钥。

如何连接不同品牌的设备？
  1. 在目标设备上安装或启用有系统操作能力的服务，按系统要求授权。
  2. 通过适配器将该服务接入 SafePause 网关；每个目标设备使用独立受控连接。
  3. 填写该设备的 HTTPS 网关地址与访问密钥，探测其实际工具。网关须允许当前网页来源。

网页运行在哪台手机上，不代表工具就会操作这台手机；调用的是网关实际连接的目标设备，发送或拨号前必须核对。

Android 需要实际设备服务；鸿蒙需要对应系统版本的服务或适配器；iPhone 若无可用接口则使用本人确认的系统拨号/短信入口。当前尚未完成所有系统的原生适配。

导入 Skill 只提供操作规则；实际运行它还需要模型、智能体运行环境和设备工具。当前静态托管没有运行这些服务。
