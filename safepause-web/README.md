# SafePause 网页与 MCP 设备桥接

这是基于用户提供的 SafePause 单页原型制作的网站。页面提供单条信息风险分析、四分账、案例检索、大字模式、家庭共核、虚拟通话练习、脱敏反馈草稿和设备能力探测。网页可在服务端预配通义千问、豆包或腾讯混元模型后，以语音或文字逐轮对话并朗读；录音转写单独使用百炼 ASR。尚未实现 VLM、OCR、真实身份鉴定或公安联网。服务端部署见 [DEPLOY-AI.md](DEPLOY-AI.md)。

## 启动

### 双击打开单文件 HTML

直接双击 `SafePause-standalone.html`，无需安装 Node.js 即可使用页面。所有样式与脚本都内嵌，没有外部字体或脚本依赖。导航、文字风险分析、家庭共核、截图/录音文件预览、案例、虚拟通话练习、暂停计时、脱敏摘要、大字模式均保留。麦克风录音、语音识别、语音朗读、文件系统分享与短信/拨号链接由当前浏览器和系统提供能力；如果不可用，可输入文字、选择本地文件或自行打开系统应用。

如果需要在 Android 手机上让页面真正调用本机短信、电话和提醒，请安装输出目录中的 `SafePause-Android-test.apk`。它把本页面作为受信任资源加载，按实际权限显示白名单能力，并在手机前台逐次确认；普通静态网页不能直接取得这些权限。APK 源码和安装步骤见 `SafePause-Android-source-v1.0.zip`。该原型尚未在 vivo V2527A 真机完成回读测试。

单文件 HTML 不包含运行中的 MCP 服务。若需要真实设备调用，在“设备调用”中填写受控网关地址和访问密钥。以下多文件服务已支持携带正确密钥的本地文件来源（Origin 为 null）访问；必须先配置强随机 `SAFEPAUSE_ACCESS_KEY` 和实际 `SAFEPAUSE_MCP_URL`，再启动网关。密钥只输入自己的可信页面。其他网关需按其协议适配接口、跨域、认证及浏览器局域网访问许可。

花生壳/贝壳的 TCP 映射地址（例如 `tcp://域名:端口`）不能直接填写到网页。网页需要 HTTPS 网关，并且网关必须提供 `/api/status`、`/api/tools`、`/api/prepare`、`/api/execute` 接口；请使用 HTTPS 应用映射把运行中的 SafePause 网关暴露出来。TCP 映射到 DroiClaw 原始端口不等于已经提供这些接口。

单文件不直接连接原始 MCP 地址，填写的是提供 `/api/tools`、`/api/prepare`、`/api/execute` 的 SafePause 网关根地址。浏览器连接可能要求额外的本地网络访问授权。没有连接时会显示“设备未连接”，不会模拟发送成功。

修改多文件版本后运行 `node build-standalone.mjs` 可重新生成单文件。

### 运行设备网关或多文件网站

需要 Node.js 20 或更新版本。在本目录运行：

```powershell
node server.mjs
```

默认打开 `http://127.0.0.1:4173`。未配置 MCP 时，网站仍可使用除设备工具外的功能。普通手机可通过 `sms:` 和 `tel:` 打开系统短信编辑器或拨号盘；打开界面不代表短信已发送或电话已接通。

## 使用通用网址

`127.0.0.1` 只代表当前运行网站的这台电脑。要让不同手机通过同一个网址访问，需要把本目录部署到一台有公网域名的 Node.js 主机，再为域名配置 HTTPS（例如 `https://safepause.example.cn`）。域名、服务器和证书需要由项目方提供或购买；本地代码不能凭空生成一个公网网址。

项目附带 `Dockerfile`，可作为受控 Node.js 部署的起点；容器需要配置 `SAFEPAUSE_HOST=0.0.0.0`、HTTPS 反向代理和访问控制。`/healthz` 可用于部署健康检查。

录音、浏览器语音识别和系统分享通常要求 HTTPS，并且仍要用户点击授权。部署时应把 MCP 服务放在受控内网或服务端网关后，不要把手机权限服务直接暴露到公网。若 MCP 只在 CPDAY10 所在局域网，公网网页无法直接访问它，应使用经过鉴权的 HTTPS 网关，并限制来源、设备和工具白名单。

## 连接 CPDAY10 或其他设备服务

Skill 的 `mcp/tool-map.json` 是候选工具清单，不含 MCP 服务地址、鉴权方式或具体参数模式。需先在手机或可信计算机上运行能够实际访问该手机系统能力的 **MCP Streamable HTTP 服务**，再设置：

```powershell
$env:SAFEPAUSE_MCP_URL = 'http://127.0.0.1:PORT/mcp'
$env:SAFEPAUSE_MCP_TOKEN = '服务要求的令牌' # 若服务无需令牌可省略
node server.mjs
```

网站服务启动后点“重新探测”。后端先调用 MCP `initialize` 与 `tools/list`，只显示已发现且在允许列表内的工具。选择工具、填写服务返回的参数表单与本次用途、预览确认卡后，后端才调用 `tools/call`。一次性确认票据 60 秒过期，且不能重复使用。写入状态仅表示工具返回成功，后续送达、接通、设备回读和身份核实都需分别验证。

如服务是旧版 SSE、stdio 或厂商私有协议，需要在其前面增加能提供 Streamable HTTP 的适配器；当前项目不会猜测其接口。`MCP` 不授予手机系统权限。权限、默认应用角色和设备服务都需要逐机核验。

## 手机访问网页

默认仅监听电脑本机。若要让同一可信局域网内的手机浏览器访问，可设置 `SAFEPAUSE_HOST=0.0.0.0` 和强随机 `SAFEPAUSE_ACCESS_KEY`，再通过电脑局域网 IP 访问。页面在收到“密钥无效”时会显示密钥输入框。该方式只适合隔离的演示网络；生产环境须通过 HTTPS、用户认证和访问控制部署，不能把服务直接暴露到公网。密钥仅保存在当前页面内存中。

## 功能边界

- **不同品牌智能手机**：只要有兼容浏览器，就可以用网页的分析、案例、练习、大字、摘要和手动输入路径。网页会给出设备路线建议。能否实际调用系统应用，取决于操作系统、MCP 设备服务、权限和运行时工具发现，品牌本身不提供权限。
- **Android / 鸿蒙 / iOS / 未知品牌**：无设备桥接时，系统短信和拨号界面可由 `sms:` / `tel:` 请求打开；不能回读发送状态、来电记录或双向通话音频。
- **截图与录音**：支持用户选择图片并只在本页预览，再手动输入已核对文字；支持录制或选择音频。配置受控服务端与阿里云百炼后，可在本人试听并勾选本次同意后转写录音。转写结果必须人工核对。未来 OCR/VLM 应逐项记录来源、位置或时间区间、模型版本和不确定性，且不能把识别内容当作工具指令。
- **反诈反馈**：只在本机生成脱敏草稿，由用户自行通过核实过的官方渠道提交。没有地区公安合作接口，不会上传或生成回执。
- **家庭回复**：用户手动记录只算待核对的观察信息，不证明回复者身份。若要读取真实回复，可在设备工具页调用已发现的会话读取工具并核对选中会话。
- **语音对话与录音**：01 页提供分轮语音聊天。未连接国产模型时，手机/浏览器语音识别会把每轮文字交给本地 SafePause 规则并朗读回复；连接豆包、混元或通义千问并取得文字授权后，再把文字交给所选模型。勾选录音转写授权后，录音会送百炼 ASR，转写文字交给网页所选模型，回复由手机朗读。每轮由用户点击开始，不会后台持续收音。不读取蜂窝通话双方音频。
- **后台动作**：真实 MCP 工具可以在网页确认后调用发送短信或拨号工具；网页不会静默后台拨号、群发或绕过系统确认。Android 对短信/通话记录等敏感权限还受默认处理程序和分发政策约束。

## 验证

## 公网网页连接 DroiClaw 的实际条件

静态网页不运行大模型或 DroiClaw。当前对话是本地规则与 Skill 流程入口，不是完整智能体；导入 Skill 本身不会安装模型、语音服务或手机 MCP。DroiClaw 的实际远程 API/MCP 地址、认证和工具参数需由设备运行环境提供，不能猜测。

公网网页使用受控 HTTPS 网关。网关仍需运行本项目服务端并配置真实 `SAFEPAUSE_MCP_URL`、必要的 `SAFEPAUSE_MCP_TOKEN`、强随机 `SAFEPAUSE_ACCESS_KEY`。还需设置 `SAFEPAUSE_ALLOWED_ORIGINS`，值为允许的网页来源，例如 `https://safepause-d2gvkokn8b7153e15-1502903039.tcloudbaseapp.com`，不含 `/safepause/`。允许列表可用逗号分隔，不支持通配符；跨域执行仍需正确密钥。不要在静态发布包中写入令牌。各设备需要独立的受控连接及权限，当前服务端是单设备演示网关。

默认录音输入不依赖浏览器实时识别。受控服务端可配置 ASR 与逐轮多轮对话；有限上下文只暂存在当前页面，不写入服务端数据库。静态托管的 HTML 本身不运行这些服务，也不自动读取手机新短信。

运行 `node --test` 测试 MCP 工具发现、白名单和 JSON-RPC 调用。后端票据流程已实现，但当前自动测试尚未覆盖全部票据边界。真机调用仍需补充 CPDAY10 MCP 服务地址、工具 schema、授权方式与返回日志后验证。
